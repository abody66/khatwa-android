# تطبيق خطوة (Android)

هذا مشروع أندرويد كامل وجاهز للبناء، يحوّل تطبيق "خطوة" من PWA إلى تطبيق أندرويد أصلي (APK).

## كيف يعمل بدون إنترنت وكيف يُخزَّن البيانات على الجهاز

- كل ملفات التطبيق (HTML/CSS/JS والأيقونات) موضوعة داخل مجلد `app/src/main/assets/www`
  ومضمّنة **فعليًا داخل ملف الـ APK نفسه**. التطبيق لا يحمّل أي شيء من الإنترنت مطلقًا —
  حتى من أول مرة تفتحه فيها.
- تم حذف رابطي خطوط Google Fonts الخارجيين من `index.html` (كانا يحتاجان اتصالاً
  بالإنترنت). الخطوط سترجع تلقائيًا لخطوط أندرويد الافتراضية التي تدعم العربية بشكل جيد.
  إذا أردت لاحقًا نفس الخطوط الأصلية (Reem Kufi / IBM Plex Sans Arabic) بالضبط،
  حمّل ملفات الخط (.ttf) وضعها في `app/src/main/assets/www/fonts/` وأضف `@font-face`
  في أعلى الـ CSS داخل `index.html`.
- ملف AndroidManifest.xml **لا يطلب إذن الإنترنت إطلاقًا** — لأن التطبيق لا يحتاجه.
- التخزين (المهام، السلسلة اليومية، الثيم) يستخدم `localStorage` كما في التطبيق
  الأصلي، وهو مفعّل داخل WebView (`setDomStorageEnabled`) ويُحفظ في مساحة بيانات
  التطبيق الخاصة على الجهاز — لا يُرسل لأي خادم.

## الطريقة الأولى: بدون تثبيت أي برنامج (عبر GitHub Actions)

هذه أسهل طريقة إذا ما عندك Android Studio:

1. أنشئ حساب مجاني على github.com إذا ما عندك واحد.
2. أنشئ مستودع (Repository) جديد فاضي (خاص أو عام، مو مهم).
3. ارفع كل ملفات هذا المشروع بالكامل (بما فيها مجلد `.github`) إلى المستودع
   (تقدر تسحب وتفلت الملفات من صفحة المستودع في المتصفح: Add file → Upload files).
4. بعد الرفع، روح لتبويب **Actions** في المستودع — بيبدأ بناء تلقائي اسمه
   "Build APK" (يأخذ بضع دقائق).
5. لما يخلص (علامة ✓ خضراء)، افتح التشغيلة (run) واضغط على **khatwa-debug-apk**
   تحت قسم Artifacts لتنزيل ملف الـ APK جاهز للتثبيت.
6. انقل الملف لجوالك وثبّته (فعّل "السماح بالتثبيت من مصادر غير معروفة" لمتصفحك
   أو مدير الملفات إذا طلب منك أندرويد ذلك).

## الطريقة الثانية: عبر Android Studio (على جهاز كمبيوتر)

1. نزّل وثبّت Android Studio مجانًا من: https://developer.android.com/studio
2. افتح Android Studio → Open → اختر مجلد المشروع هذا بالكامل (`khatwa-android`).
3. إذا ظهرت رسالة عن "Gradle wrapper" غير موجود، اختر السماح لـ Android Studio
   بإنشائه تلقائيًا (هذا طبيعي، المشروع ما فيه wrapper مضمّن لتصغير الحجم).
4. انتظر حتى تنتهي عملية "Gradle Sync" (أول مرة تحتاج إنترنت لتنزيل أدوات البناء
   فقط — هذا لا علاقة له بعمل التطبيق نفسه بدون إنترنت لاحقًا).
5. من القائمة: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
6. لما يخلص البناء، بيظهر إشعار فيه رابط **locate** يوديك مباشرة لملف
   `app-debug.apk` داخل `app/build/outputs/apk/debug/`.

## ملاحظة عن التوقيع

الـ APK الناتج من الطريقتين موقّع بتوقيع "debug" — يعني تقدر تثبته وتشغّله على
جهازك مباشرة بدون مشاكل، لكنه غير مناسب لرفعه على Google Play. إذا احتجت لاحقًا
تنشره على المتجر، تحتاج تنشئ مفتاح توقيع "release" خاص بك — أقدر أساعدك بهذا لو
احتجته.
